Firmware

Version-

Die Prüfung läuft nur im Hintergrund und zeigt ein Symbol am Display. Installiert wird nur hier über "Update installieren" — oder, wenn "Automatisch installieren" an ist, von selbst beim nächsten Fund der Hintergrundprüfung (nie während ein Ladepunkt lädt oder das Display gerade berührt wurde). Ein manuelles "Auf Update prüfen" (hier oder am Display) installiert nie von selbst, auch nicht bei aktiviertem "Automatisch installieren". Das Display selbst kann Updates nicht mehr installieren.

WLAN

Setzt die WLAN-Zugangsdaten zurück und startet das Display im Einrichtungsmodus neu. Die gleiche Aktion ist auch direkt am Display per langem Druck auf die obere Fläche möglich — nützlich falls diese Weboberfläche nicht mehr erreichbar ist.

Sicherheit

Ohne PIN ist diese Weboberfläche für jeden im selben WLAN ohne Anmeldung erreichbar. Optional einen PIN setzen, um Einstellungen, Firmware-Updates und WLAN-Reset zu schützen. Bei der Anmeldung als Benutzername user und als Passwort den PIN eingeben.

PIN-Schutz-

PIN vergessen? Es gibt keinen Reset dafür außer einem erneuten Flashen mit aktivierter Option "Erase device".
