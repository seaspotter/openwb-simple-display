Firmware installieren

Funktioniert in Chrome oder Edge auf einem Desktop-Computer. Der Browser braucht Zugriff auf USB-Seriell-Ports, was nur Desktop-Chromium-Browser unterstützen.

  1. Verbinde das Display per USB-C-Kabel mit deinem Computer (ein Kabel, das Daten übertragen kann, nicht nur ein Ladekabel).
  2. Klicke unten auf Installieren und wähle den seriellen Port aus der Liste (meist "USB Serial" oder ähnlich benannt). Ein Druck auf den BOOT-Knopf ist nicht nötig — das Board wechselt selbstständig in den Flash-Modus.
  3. Flasht du das Board zum ersten Mal? Setze ein Häkchen bei Erase device, um die werkseitig vorinstallierte Demo-Firmware zu entfernen. Spielst du nur ein Update auf? Lass das Häkchen weg, damit WLAN- und openWB-Einstellungen erhalten bleiben.
  4. Nach dem Flashen mit dem Handy oder Computer das WLAN openwb-simple-display-setup verbinden, um die Einrichtung abzuschließen.
Dein Browser kann keine Firmware installieren — versuche es mit Chrome oder Edge auf einem Desktop-Computer. Diese Seite muss über https ausgeliefert werden, um Firmware installieren zu können (das ist bei GitHub Pages bereits der Fall — versuche, die Seite neu zu laden).

Problembehandlung

Wenn die Portliste leer ist oder der Flash-Vorgang mittendrin abbricht, das USB-C-Kabel abziehen und wieder anschließen, sicherstellen, dass es ein Datenkabel ist (kein reines Ladekabel), und es erneut versuchen. Unter Windows wird je nach USB-Seriell-Chip des Boards eventuell der CH340-USB-Treiber benötigt, falls kein Port angezeigt wird.
